# Privacy Policy

This Privacy Policy is subject to updates, so we recommend revisiting it periodically.

"Voice AI Assistant" does not collect any personal data. All user preferences (wake words, settings) are stored locally on your device and never transmitted externally.

To adapt to ChatGPT's frequent DOM changes, the extension fetches an updated static file from a GitHub-hosted repository. This file provides the necessary information for the extension to function properly. No user data is sent in this request.

We encourage users to review GitHub's [Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) for more details about their data handling practices.
